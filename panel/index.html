GelSVG panel format

This address is the name a GelSVG file gives its panels: the data of each panel in a .gel.svg file says "format": "https://gelsvg.github.io/panel".

GelSVG is an open format for gel and blot figures that carry their own data. Its specification is a draft, to be published as GelSVG 1.0; this page will then point to it. Until then, files are written in the draft, GelSVG 0.1 (schema_version 0, schema_revision 1).

To see what a file holds, open it in the GelSVG Viewer. The gelsvg library reads and writes the format.
